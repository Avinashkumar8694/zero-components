Zero Checkbox - Lit Component Example

How to Load a Lit Component

This page demonstrates loading the zero-checkbox Lit component from the server.

1. Include the Component Script

<script type="module" src="http://localhost:5555/service/plugins/zero-checkbox/zero-checkbox.js"></script>

2. Use the Component in HTML

<zero-checkbox-1.0.0 label="Accept Terms" description="I agree to the terms and conditions" value="terms-accepted"></zero-checkbox-1.0.0>
